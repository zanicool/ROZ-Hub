# ROZ Hub — Linux

ROZ HE Keyboard Configurator by Republic of Zani.

## Install
```bash
chmod +x install.sh && sudo ./install.sh
```

## Run
After install, open **ROZ Hub** from the app menu. Pin it to the GNOME dash/taskbar by right-clicking the icon and choosing *Pin to Dash*.

Or from a terminal:
```bash
roz-hub
```

## Uninstall
```bash
chmod +x uninstall.sh && sudo ./uninstall.sh
```

## Requirements
- Python 3
- tkinter (installed automatically by install.sh)
